# End-to-End-Weather-Data-Engineering-Project

![DAG](https://github.com/cann-emma/End-to-End-Weather-Data-Engineering-Project/blob/main/assets/weather_dag_2-graph.png)

An end-to-end data engineering project that automates the ingestion, transformation, and loading of weather and population data using Apache Airflow. The pipeline integrates Python, PostgreSQL, and Amazon S3 to build a scalable ETL workflow for analytics-ready datasets.
